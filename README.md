# Marzia Akter Mita — Portfolio Website

A responsive HTML/CSS/JavaScript portfolio inspired by the clean, minimal personal-resume style of the Ramsay reference.

## Preview locally
1. Extract `marzia-portfolio.zip`.
2. Open `index.html` in Chrome, Edge, Firefox, or Safari.
3. Keep the `assets` folder beside `index.html` so the portrait loads correctly.

## Files
- `index.html` — all portfolio content and structure
- `style.css` — responsive layout, colors, animations, and mobile breakpoints
- `script.js` — mobile navigation, scroll reveal, role typing, portfolio filters, email copy, and scroll progress
- `assets/marzia-profile.jpg` — supplied profile portrait

## Easy edits
- Update contact information in `index.html`.
- Edit portfolio project names and URLs in the Portfolio section. The current design highlights nine projects from the supplied CV.
- Change colors at the top of `style.css` in the `:root` variables.
- Skill levels are visual estimates; adjust the `--level` values in `index.html` to match your preference.

## Notes
- This is a static website, not a WordPress theme.
- Contact uses an email link; it does not submit to a backend.
- Some details from the CV that are not needed for a public portfolio (such as NID, birth date, parents' names, and religion) were intentionally left out.
